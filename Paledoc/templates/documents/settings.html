End-to-End Processing Architecture
  1. PDF Extraction: PyMuPDF loads document pages without quality loss.
  2. Recursive Chunking: 500-char chunks with 100-char overlap preserve semantic boundaries.
  3. Metadata Tagging: Injects doc_id, user_id, page, and deterministic sha256 chunk IDs.
  4. ChromaDB Indexing: MiniLM-L6-v2 creates 384-dimensional dense vectors.
  5. Hybrid Retrieval:
    • Top-10 Semantic similarity search via ChromaDB
    • Top-10 Keyword search via BM25 Okapi
  6. Reciprocal Rank Fusion (RRF): Fuses semantic and lexical ranks using standard RRF (k=60).
  7. Cross-Encoder Reranking: MS-MARCO Cross-Encoder evaluates query-chunk cross-attention to select top 3 candidates.
  8. Grounded Generation: Qwen3.5:4B synthesizes answers with source citations and strict zero-hallucination rules.
Multi-Tenant Security Guarantee:

All document retrieval, BM25 indexing, conversation histories, and vector deletions are strictly filtered by request.user.id on the server. Front-end tampering cannot bypass ownership boundaries.
